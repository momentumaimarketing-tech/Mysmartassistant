# Mysmartassistant

AI-powered productivity app for teams and professionals. Built with React and Tailwind CSS.

## 🚀 Features
- **Task Prioritizer:** Sort and manage your work by priority, effort, and dependencies.
- **Drafting Assistant:** Instantly generate emails and meeting agendas.
- **Meeting Summarizer:** Extract action items, decisions, and highlights.
- **Premium Upgrade:** Unlock unlimited usage and advanced features.
